## 0. "จบโปรเจกต์" แปลว่าอะไร (นิยามที่ใช้ตัดสิน)

ถือว่าจบเมื่อครบทั้ง 6 ข้อ — ขาดข้อใดข้อหนึ่งยังไม่จบ:

1. **ไม่มีงานประจำวันไหนที่ต้องมีคนรันสคริปต์ด้วยมือ** (วันนี้ยังมี: `aim_link_person --all` แก้แล้ววันนี้ · `aim_person_map_sync` · `admin/summary` แบบสั่งมือ)

3. **ระบบไม่ตายตามเครื่องเดียว** — ข้อความ LINE ไม่หายเมื่อ cim-server ดับ (ขั้นที่ 2) **หรือ** มีตัวเลขพิสูจน์ว่าเครื่องแทบไม่ดับจนไม่ต้องทำ
4. **ทุกทางที่ย้ายไปแล้วมีสคริปต์ถอยกลับที่ซ้อมบน clone แล้ว** (มาตรฐาน `move_line_user.php`)
5. **ยามครอบทุกจุดที่เคยพังเงียบ** — โดยเฉพาะ "ยิงผ่านทางเข้าจริง" (worker) ไม่ใช่เทสต์ชั้นไลบรารีอย่างเดียว
6. **เอกสาร 3 ไฟล์ตรงกับของจริง**: `IMPLEMENTATION_PLAN.md` §2 (as-built — เขียนใหม่ 2026-09-10 · ของเดิมอยู่ §2-เดิม) · `AS_BUILT.md` (สภาพจริง + ตัวเลข) · `CLAUDE.md` (กติกา) — ไม่มีข้อความขัดกัน
