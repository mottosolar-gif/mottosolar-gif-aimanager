01 · ผังเทียบแบบ

สี่ชั้นที่วางไว้ สร้างจริงได้สองชั้น — และวันนี้เพิ่มชั้นควบคุมเข้ามาหนึ่ง

แบบเดิมให้คลาวด์เป็นประตูหน้า แล้วส่งงานหนักลง homelab ก่อนค่อยไปอ่าน cim-server · ของจริงกลับด้าน — LINE ลงที่เครื่อง PHP ก่อน แล้วเครื่องนั้นส่งต่อขึ้นคลาวด์ · ใหม่วันนี้: GitHub อยู่เหนือทั้งสองเครื่อง ใครแก้โค้ดต้องผ่านมัน

ข้อเท็จจริงที่เปลี่ยนวิธีคิดทั้งแผน

แบบวาด : LINE → Worker ① → คิว → homelab ② → อ่าน cim ③ ของจริง : LINE → vendor-ksk PHP → aim_forward_events() → Worker ① → กลับมาออกทาง vendor-ksk → LINE

Worker พูดกับ LINE เองไม่ได้ ⇒ cim-server ล่ม = คลาวด์ใบ้ทันที · การย้ายตรรกะขึ้นคลาวด์ทีละชิ้นจึงไม่แก้จุดตายจุดเดียว — นี่คือเหตุผลที่แผน “ย้ายสมอง 5 ชิ้น” ถูกตัดทิ้งวันนี้ และเหตุผลที่วัด downtime ก่อนจะสร้างอะไรเพิ่ม
