## สิ่งที่พบ เรียงตามผลกระทบต่อพนักงานจริง

**1 · ด่านความรู้ `qa_index` ดักคำถามข้อมูลก่อนคลาวด์ (wrong-layer 9)**
วลีในสารบัญ `tbl_qa_phrase` — `งานของฉัน` · `งานค้าง` · `มอบหมายงาน` · `วันลา` · `ทำอะไรได้` — เป็นคำเดียวกับ intent คลาวด์ ⇒ "ใครมีงานค้างเยอะที่สุด" ได้ "ดูที่ปุ่มริชเมนู งานของฉัน" · "วันลาเหลือกี่วัน" ได้วิธี*ขอ*ลา
ด่านนี้ตั้งใจให้ยืนหน้า**โหมดคุยเล่น** (2026-09-01) แต่มันยืนหน้า**เครื่องตอบข้อมูล**ด้วย
→ แก้ที่ **ข้อมูล ไม่ใช่โค้ด**: ตัด/แคบ 5 วลีนั้นในหน้า `qa_index.php` (เครื่องมือที่มีอยู่) หรือให้คำถามที่ขึ้นต้น "AI" ผ่านคลาวด์ก่อน qa_index (โค้ด S)

**2 · กฎ intent คลาวด์แคบเกิน (missed-intent 21 = ก้อนใหญ่สุด)**
กฎเป็น "ต้องมีคำครบชุด" เช่น `my_done_today` = งาน+เสร็จ+วันนี้ ⇒ "วันนี้เสร็จได้กี่ใบ" ไม่ผ่าน (ไม่มีคำว่า "งาน") · `stats_completed_month` ต้อง "เดือนนี้"+"เสร็จ"+"งาน" · `help` ต้อง "ช่วยอะไรได้"/"ทำอะไรได้" ("ทำไร" · "ช่วยเรื่องไหน" ไม่ผ่าน)
ผลคือคำถามธรรมดา 19 ข้อหลุดไป LLM ซึ่ง**ไม่มีสิทธิ์อ่านข้อมูล** แล้วตอบ "ไม่มีข้อมูล" — ผู้ใช้เข้าใจว่าระบบทำไม่ได้ ทั้งที่ทำได้
→ แก้ที่ `worker/src/queryEngine.ts` rules: เพิ่มคำพ้องต่อ intent (ใบ/อัน/กี่ · ปิดงาน=เสร็จ · เลยกำหนด/เกินกำหนด/overdue · ทำไร/ช่วยไร) — มี corpus 40 ข้อนี้เป็นยามได้ทันที (`queryEngine.test.ts`)

**3 · อังกฤษ: คลาวด์จับไม่ได้เลย · LLM ตอบว่า "ไม่มีฟีเจอร์"**
e01–e04 (show my tasks · what can you do · who has the most open · my overdue) ไป LLM ทั้งหมด · e04 ตอบว่า *"doesn't have a command for checking overdue"* ทั้งที่มี (ภาษาไทย) · e08 ถามอังกฤษได้คำตอบไทย (1/10 ผิดภาษา) · ส่วนที่ดี: ผสมไทย-อังกฤษ "ของเข้า tomorrow มีไหม" fim_qa ตอบข้อมูลจริงได้
→ เพิ่มกฎอังกฤษต่อ intent (tasks/overdue/help/most open) หรืออย่างน้อยพรอมต์ห้ามพูดว่า "ไม่มีคำสั่ง" ให้บอก "ลองถามภาษาไทยว่า …"

**4 · LLM ชนเพดาน 512 → "ยังไม่เข้าใจ"** (ยืนยันซ้ำจากเคส 04:54)
ทุกคำถามแนว "ทำอะไรได้บ้าง" ที่หลุดถึง LLM ชนเพดาน 100% (คืนนี้ 5/5 รวมโพรบ) เพราะพรอมต์สั่งให้ไล่ลิสต์คำสั่งทั้งระบบ · `tbl_ai_usage` จด Ok=1 ตอนตัดกลาง (`line_leave.php:600` Ok = HTTP 200) ⇒ selfcheck มองไม่เห็น
→ `ll_chat_reply` 512 → 1024 + จด Ok=0 error `max_tokens` ที่ตัวห่อ (จุดเดียว ครอบ 15 จุดเรียก) + selfcheck บรรทัด "LLM ถูกตัดกลาง 7 วัน"

**5 · LLM แต่งของที่ไม่มี (fake-command 2 · invented-data 1)**
c20 ชวนให้ "พิมพ์ชื่อคน" เพื่อดูภาระงาน (ไม่มีฟีเจอร์นี้สำหรับ worker) · e07 บอกให้กดปุ่ม "Leave" บนริชเมนู (ไม่มีปุ่มนี้) · g01 "ใบขนท้ายศูนย์" ตอบเดาเป็นข้อเท็จจริงก่อนค่อยออกตัว
→ ขยายกติกาล็อกในพรอมต์ให้ครอบ "ชื่อปุ่ม/เมนู" ด้วย ไม่ใช่แค่วลีคำสั่ง · ความรู้ศุลกากรที่ไม่แน่ใจต้องออกตัวก่อนไม่ใช่หลัง

**6 · คำตอบ LLM จบกลางประโยค 3/36 โดยไม่ชนเพดาน** (c07 · c12 · c14 ยาว 60–88 ตัวอักษร จบที่ "พี่ลองพิมพ์")
ยิง c12 ซ้ำได้คำตอบเต็ม 139 ตัวอักษร 141 token ⇒ ไม่คงที่ · ตัวห่อไม่เก็บ raw response จึงสรุปสาเหตุไม่ได้
→ รวมในข้อ 4: เมื่อ reply สั้นผิดปกติหรือไม่จบด้วย ค่ะ/คะ ให้จด raw ลง log

**ที่ทำงานถูกต้องและควรคงไว้:** ปฏิเสธข้อมูลเงินเดือน (g07) · สิทธิ์ worker ถูกปฏิเสธคำถามทีมด้วยข้อความชัด (c22/c25/c29) · fim_qa ตอบของเข้าพรุ่งนี้จากข้อมูลจริง (e09) · น้ำเสียงน้องกุ้ง ค่ะ/คะ 60/60 · ความรู้ FOB/CIF · Net/Gross ถูกต้อง
